Module 07

Mathematical Foundations of the LLM Pipeline

Comprehensive, rigorous reference cards explaining the mathematical formulas, variables, and step-by-step numerical examples underpinning each transformation stage.

🔤
1. Tokenization & Type-Token Ratio (TTR)
Text segmentation & lexical richness metrics
▼

Tokenization transforms continuous text into discrete syntactic units. The Type-Token Ratio (TTR) measures vocabulary richness across a corpus.

TTR = V / N
VUnique vocabulary size (total distinct token types).
NTotal token count in the corpus.
Numerical Example: In a corpus of 100 words with 45 unique words, TTR = 45 / 100 = 0.45 (45% lexical diversity).

2. Token IDs & One-Hot Encoding
From discrete integer indices to sparse basis vectors
▼

Each vocabulary token is assigned a unique index $k \in \{0, 1, \dots, V-1\}$. A one-hot vector $\mathbf{x} \in \mathbb{R}^V$ has a $1$ at index $k$ and $0$ elsewhere.

x[i] = 1 if i = k else 0
VVocabulary size (e.g. 32,000 to 128,000 tokens).
kThe integer token ID assigned to the word.
Limitation: One-hot vectors are completely orthogonal: $\mathbf{x}_i \cdot \mathbf{x}_j = 0$ for all $i \neq j$. They capture no semantic similarity between "dog" and "cat". This necessitates dense embeddings.

3. Embedding Matrix Lookup Formulation
Efficient row indexing as sparse matrix multiplication
▼

The embedding layer stores a learnable weight matrix $\mathbf{E} \in \mathbb{R}^{V \times d}$. Multiplying a one-hot vector $\mathbf{x}_k$ by $\mathbf{E}$ selects the $k$-th row:

e[k] = x[k] · E = E[k, :]
EWeight matrix of dimensions $V \times d$.
dEmbedding dimensionality (e.g., 16 in this lab, 4096 in LLaMA-3).
eₖContinuous dense embedding vector $\mathbf{e}_k \in \mathbb{R}^d$.

4. Dense Vector Representations & Latent Space
Continuous geometric manifolds vs sparse categorical features
▼

Dense embeddings map words into a compact continuous space $\mathbb{R}^d$ where $d \ll V$. Each dimension captures a latent semantic or syntactic property:

v = [v1, v2, ..., vd] ∈ ℝ^d, ||v||_2 = 1
dLatent dimension count (16 in this lab, 768 in BERT, 4096 in LLaMA).
||v||₂L2 Euclidean norm (normalizing vectors makes dot product equal cosine similarity).
Vector Arithmetic: Learned embeddings exhibit linear compositionality: $\vec{v}_{\text{king}} - \vec{v}_{\text{man}} + \vec{v}_{\text{woman}} \approx \vec{v}_{\text{queen}}$.

5. Dot Product & Cosine Similarity
Directional alignment in continuous vector space
▼

Cosine similarity measures the cosine of the angle $\theta$ between two non-zero vectors $\mathbf{u}$ and $\mathbf{v}$, ranging from $-1$ (opposite) to $+1$ (identical orientation).

cos(θ) = (u · v) / (||u|| ||v||) = ∑(u_i · v_i) / (√(∑ u_i²) · √(∑ v_i²))
Numerical Walkthrough: Let $\mathbf{u} = [1, 2]$ and $\mathbf{v} = [2, 4]$.
$\mathbf{u} \cdot \mathbf{v} = (1)(2) + (2)(4) = 10$.
$\|\mathbf{u}\| = \sqrt{1^2 + 2^2} = \sqrt{5} \approx 2.236$.
$\|\mathbf{v}\| = \sqrt{2^2 + 4^2} = \sqrt{20} \approx 4.472$.
$\cos(\theta) = \frac{10}{2.236 \times 4.472} = \frac{10}{10} = 1.00$ (perfect collinearity).

6. Vector Distance Metrics (L1 Manhattan vs L2 Euclidean)
Spatial proximity measures for nearest neighbor classification
▼

Geometric distance quantifies vector divergence. Euclidean distance ($L_2$) measures straight-line distance, while Manhattan distance ($L_1$) measures grid-aligned coordinate differences:

d_L2 = √(∑ (u_i - v_i)²), d_L1 = ∑ |u_i - v_i|
dL2Euclidean L2 distance (sensitive to large single-dimension outliers).
dL1Manhattan L1 distance (robust sum of absolute deviations).

7. Principal Component Analysis (PCA) & Dimensionality Reduction
Eigen-decomposition of covariance matrix for 2D/3D projection
▼

To visualize 16-dimensional or high-dimensional embeddings in 3D space, PCA finds orthogonal axes of maximal variance. Given centered data $\mathbf{X}_c$, the covariance matrix $\mathbf{C}$ is decomposed:

C = (1 / (N - 1)) · X_c^T · X_c, C · v_k = λ_k · v_k
CSample covariance matrix ($d \times d$).
vₖEigenvector corresponding to the $k$-th largest eigenvalue.
λₖEigenvalue representing the variance preserved along axis $\mathbf{v}_k$.

8. Scaled Dot-Product Self-Attention Preview
How embeddings dynamically interact in transformer attention heads
▼

Once token embeddings enter the Transformer, they project into Query ($\mathbf{Q}$), Key ($\mathbf{K}$), and Value ($\mathbf{V}$) matrices. The pairwise attention weights reflect pairwise dot products:

Attention(Q, K, V) = softmax((Q · K^T) / √d_k) · V
Q, K, VQuery, Key, and Value projection matrices.
√dkScaling factor preventing gradient vanishing in high dimensions.
softmaxNormalizes rows into probability distributions summing to 1.
